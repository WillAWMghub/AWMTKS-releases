# AWM Weighbridge - releases

This page holds the installers for the AWM Weighbridge program.

- Each entry under **Releases** is one version of the program, with its installer
  (`WeighbridgeSetup-<version>.exe`) attached.
- The program checks this page for updates from its admin menu.
- This repository is for downloads only - the program's source code is not published here.
- The program needs a licence for your PC to run. Installing it does not include one.
